隱私權與資料保護政策

適用於 Android 平台

本頁說明 OCREditor 在 Android 裝置上的資料流。打包後的 App 以裝置端 OCR 為主；若您主動切換到 Gemini 雲端 OCR，所選圖片區域會送往 Google 的 Gemini API。

1. 處理模式與資料流

  • 預設為本地處理： 原生 OCR、瀏覽器 Tesseract OCR、背景修補、文字編輯、格式套用、區域刪除、區域複製/貼上與匯出都在您的裝置上完成。
  • 雲端 OCR 為選用功能： 只有在您主動選擇 Gemini OCR、輸入 API Key，並執行重新辨識或區域 OCR 時，圖片資料才會傳送到 Gemini API。其處理受 Google 的服務條款與隱私政策約束。
  • 無廣告追蹤： 文件頁與編輯器不內建廣告 SDK，也不將編輯內容主動回傳到我們的伺服器。
  • Android App 使用裝置端 OCR： 打包後的 App 可直接呼叫 Android OCR / ML Kit，不需要連到 localhost 伺服器。

2. 本機儲存、快取與暫存資料

為了讓編輯器正常運作，系統可能會在瀏覽器或本機建立下列資料：

  • 設定與偏好： UI 語言、OCR 引擎、字型偏好、單字微調模式、是否自動 OCR 等設定會保存在本機瀏覽器儲存空間。
  • 編輯歷史： 復原/重做歷史主要保存在目前工作階段的記憶體中，用來維持畫布操作。
  • 模型與快取： 若您下載 AI 背景修補模型，模型檔會快取在本機瀏覽器或應用程式儲存空間，供後續重複使用。
  • 匯出與檔案控制： 使用「儲存圖片」或「另存新檔」時，檔案只會寫到您選擇的位置或觸發瀏覽器下載。

3. 權限與平台行為

Android 版常見權限與行為如下：

  • 照片或檔案存取： 只用於讀取您挑選的圖片，與儲存匯出結果。
  • 相機權限： 若您使用拍照匯入，影像只在本機處理，不會自動上傳給我們。
  • 字型與系統資源： App 會使用裝置可用字型來呈現文字，不會上傳字型清單。
  • 硬體加速： OCR、背景修補與畫布渲染可能使用 GPU 或系統 AI 加速框架，但不會讀取與本軟體無關的檔案內容。

4. 您可自行控制的網路行為

  • 若不想使用任何外部服務： 保持使用原生 OCR 或瀏覽器 Tesseract，並不要輸入 Gemini API Key。
  • 關閉自動 OCR 也可行： 您可先只載入原圖，確認後再手動執行辨識。
  • 匯出仍在本地完成： 就算您先前使用過雲端 OCR，最終的畫布編修與匯出檔案仍只在您的裝置上產生。

5. 政策更新

若文件、功能或資料流有重大調整，我們會更新本頁內容。是否使用雲端 OCR 仍由您自行決定與啟用。
